# 2.0T DOHC 16V 汽车发动机 3D 拆解与四冲程数字孪生演示台 (Three.js)

基于 **Three.js (WebGL2 + PBR + PostProcessing + CSS2DRenderer)** 纯代码参数化高精度构建的 **直列四缸 2.0T 双顶置凸轮轴 16气门缸内直喷涡轮增压发动机（Inline-4 2.0T DOHC 16V Turbo GDI）** 交互式 3D 拆解与运动仿真系统。

## 🚀 快速启动
- **零依赖直接双击运行**：直接双击项目根目录下的 `启动预览.bat` 或 `index.html` 即可在浏览器中离线流畅运行（已内置打包 Three.js r187 与全部后期扩展库，无需联网或启动本地服务器）。

## 🔧 核心机械结构与功能亮点

### 1. 8大子系统 · 35项独立高精度机械总成
1. **DOHC 配气与气缸盖系统**：机油加注口盖、红头铭牌气门室罩盖（含橡胶密封垫）、10道凸轮轴轴承盖、进气凸轮轴（8桃尖）、排气凸轮轴（8桃尖+HPFP四方驱动桃）、8支进气门+变螺距三维螺旋弹簧+挺柱、8支钠冷排气门+螺旋弹簧+挺柱、DOHC 16V屋脊燃烧室铝合金气缸盖、MLS三层不锈钢气缸垫（含紫铜密封火环）。
2. **气缸体与主轴承总成**：闭式水道铝合金气缸体（含45°激光交叉网纹珩磨气缸套与网格加强筋）、5道锻钢主轴承盖与10颗ARP主轴承螺栓。
3. **曲柄连杆与活塞核心**：42CrMo4全平衡8扇叶锻钢曲轴、4支涡轮凹顶活塞（带气门避让坑与石墨减摩裙部涂层）、12道活塞环（镀铬气环+刮油环+组合油环，拆解时三层自动分离）、4支全浮式DLC活塞销与卡簧、4支H型锻造连杆（拆解时涨断大头瓦盖与ARP螺栓自动下移分离）。
4. **点火与350Bar GDI高压直喷系统**：4支红头独立点火线圈与线束轨、4支激光双铱金火花塞、不锈钢高压共轨与4支侧置直喷喷油嘴、凸轮机械驱动高压燃油泵（HPFP）。
5. **正时链条与前端附件轮系（FEAD）**：进排气双VVT液压相位调节器（42齿:21齿精确2:1传动比）、72节实时沿导轨滚动的金属静音正时链条+耐磨尼龙导轨+液压张紧器、压铸铝正时前盖、曲轴谐波减振皮带轮、6PK多楔蛇形皮带与自动张紧轮、150A镂空交流发电机（可见内部紫铜定子绕组）、离心式水泵与变排量空调压缩机。
6. **谐振进气与电子节气门系统**：四歧道等长谐振进气歧管与稳压腔、CNC电子节气门体（内置随转速/油门实时旋转开合的黄铜蝶阀片！）与高流量锥形冬菇头空滤。
7. **排气歧管与双流道涡轮增压器**：四合一等长不锈钢排气歧管（高转高温红热发光）、冷热双阿基米德渐开蜗壳废气涡轮增压器（内置6+6分流叶片5轴CNC超高速飞旋叶轮、水冷CHRA轴承体、旁通废气阀执行器与头段排气管）。
8. **润滑油底壳与飞轮离合系统**：百叶防浪挡油板+转子机油泵+集油器滤网、底部11片纵向风冷散热鳍片铝合金油底壳、旋装机油滤清器与黄色拉环机油尺、72齿双质量飞轮+带4组减振螺旋簧的离合器摩擦片+18爪膜片弹簧压盘。

### 2. 四种工业观察模式与多级爆炸拆解
- **无级分级爆炸拆解（0% ~ 100%）**：严格遵循先外盖附件、再进排气正时、后缸盖油底壳、最终展开活塞环与连杆瓦盖的真实工艺次序；同时支持**按子系统单独拆解**与**单个零件独立抽出**。
- **外壳半透明透视（X-Ray）**：一键将外部壳体化为科技蓝半透明材质，免拆解透视内部运转核心。
- **实时三维动态剖切（Section Cutaway）**：支持沿纵向（默认精准切开第1缸中心）或横向无级推拉解剖刀平面。
- **四冲程实时遥测与慢动作教学**：直观呈现直列四缸 `1-3-4-2` 点火顺序下的吸气（冰蓝+GDI油雾）、压缩（琥珀升温）、做功（火花塞电弧闪光+金橙火焰膨胀）、排气（暗红废气）全过程。
